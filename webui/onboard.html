運営者から受け取った 招待コード と、楽天RMSで発行した情報を入力してください。入力した認証情報は暗号化して保管され、運営者の画面・シート・ログには表示されません（詳細は下部「取扱いについて」）。

3. 楽天ペイ受注API のキー

RMS →「店舗設定」→「WEB API」で 楽天ペイ受注API を利用申請し、serviceSecret と licenseKey を発行してください。licenseKey には有効期限（通常1年）があります。

4. あんしんメルアド SMTP

RMS →「メール」→「あんしんメルアドサービス」→ SMTP設定 で発行した ID とパスワード。店舗名義でお客様のマスクアドレスへ送るために必要です。

取扱いについて

    
    
      
  • serviceSecret / licenseKey / SMTP パスワードは、サーバ側で暗号化してから保存します。運営者の画面・スプレッドシート・実行ログには平文が表示されません。
    • 
      
  • ただし、サービスが楽天へ受注取得・メール送信を行うため、システム自体は復号して利用します（「誰にも復号できない」方式ではありません）。
    • 
      
  • 受注データはこの店舗専用のスプレッドシート1ファイルに保存され、他の店舗からアクセスできる経路はありません。
    • 
      
  • お客様のログイン情報（R-Login・楽天会員ID・パスワード）は一切お預かりしません。
    • 
      
  • licenseKey は期限切れ前に、管理画面「認証情報」から更新できます（30日前に運営者へ通知が届きます）。
    • 
      
  • 解約時は、暗号化データ・トークンを削除し、スプレッドシートは店舗へ譲渡または削除します。
