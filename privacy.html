株式会社GSD（銀座杉伝。以下「当社」）は、「ステップ侍」において取り扱う情報を、次のとおり扱います。情報は「店舗（契約者）の情報」と「店舗から委託を受けて扱う購入者情報」に分けて記載します。

1. 店舗（契約者）の情報

取得する情報

  • 店舗名、店舗ID（sid）、店舗連絡先メールアドレス、控えメールアドレス
  • RMS の serviceSecret・licenseKey とその有効期限日、あんしんメルアド SMTP の ID・パスワード
  • 管理画面のログイン用パスワード、アクセストークン、レビュー取込用トークン（拡張機能用）、セッショントークン、招待コード（いずれもハッシュ値のみ保存し、元の値は保存しません）
  • 利用規約・プライバシーポリシーへの同意の記録（版と日時）
  • 請求に関する情報（プラン、課金方式、課金状態、トライアルの開始日・終了日、請求書番号・請求日等の請求メモ、状態変更の記録）。現在は請求書払いで、クレジットカード情報は取得・保持しません。
  • お問い合わせの内容

利用目的

  • 本サービスの提供・運営、本人確認、RMS への接続とメール送信
  • 利用料の請求、お問い合わせ対応、障害・期限切れ等の連絡
  • 不正利用の防止、サービス改善

お預かりしないもの

R-Login の ID・パスワード、楽天会員 ID・パスワードは取得しません。

保管

認証情報（serviceSecret・licenseKey・店舗ID・SMTP の ID・パスワード）は暗号化して保存します。運営者の画面・スプレッドシート・実行ログには表示しません。ただし、受注の取得とメール送信のため、システムは処理時に復号して利用します。表示のために平文で保持するのは、店舗ID、店舗名、licenseKey の有効期限日、および SMTP の ID の一部（伏せ字にしたもの）のみです。

管理画面のログインパスワードは平文では保存せず、ソルト付きのハッシュ値で保存します（運営者にも見えません）。アクセストークン・レビュー取込用トークン・セッショントークン・招待コードもハッシュ値のみを保存します。

2. 店舗から委託を受けて扱う購入者情報

対象となる情報

店舗専用のスプレッドシートに、次の購入者情報を保存します。購入者情報は店舗が管理する情報であり、当社は店舗の委託を受けて取り扱います。

  • 受注情報: 注文番号、受注日時、発送日、ステータス、注文者氏名、メールアドレス（RMS が返す注文者のアドレス。通常は楽天のあんしんメルアドが発行するマスクアドレス）、都道府県、商品コード・商品名・金額・点数・クーポン額、購入回数、レビューとの紐づけ
  • メール送信履歴（注文番号、種別、送信日時、結果）、クーポン発行履歴
  • レビュー（CSV アップロードの場合: 評価、投稿日、レビュー本文、購入者ニックネーム等。Chrome 拡張機能の場合: 第3節の5項目のみ）

番地を含む住所、電話番号、郵便番号は保存しません。R-Login、楽天会員ID・パスワードは取得しません。

保存する受注データの項目と用途

店舗専用スプレッドシートの「受注」に保存する項目と、その用途です（項目名のみを示し、実際のデータは記載しません）。利用規約の別表と同じ内容です。

項目区分主な用途
order_number（注文番号）識別子注文の一意キー、レビュー・送信履歴との突合
order_date / order_datetime（受注日 / 受注日時）個人を直接識別しない項目集計期間、購入回数の計算、時間帯別集計
buyer_key（購入者識別キー）個人情報（購入者の識別）同一購入者の判定、購入回数、送信履歴、クーポン判定
masked_email（メールアドレス）個人情報（メールアドレス。通常は楽天のあんしんメルアドが発行するマスクアドレス）メールの宛先、新規／リピートの判定
buyer_name（注文者氏名）個人情報（氏名）メール本文の宛名
prefecture（都道府県）個人情報の一部都道府県別の集計
item_code / item_name（商品コード / 商品名）個人を直接識別しない項目商品別の集計
amount / goods_price（金額 / 商品金額）個人を直接識別しない項目売上集計、月次レポート
units（点数）個人を直接識別しない項目点数の集計
purchase_count（購入回数）派生項目リピート判定、クーポン条件
ship_date（発送日）個人を直接識別しない項目フォロー・お礼メールの送信時期の判定
status（ステータス）個人を直接識別しない項目送信対象の判定（キャンセルの除外）、集計の母集団

coupon_shop_price / coupon_codes（クーポン額 / クーポンコード）個人を直接識別しない項目クーポン利用の集計

保存しないもの: 番地を含む住所、電話番号、郵便番号。メール送信履歴（sends）には、送信の識別子・注文番号のほか、宛先に由来する識別子（メールアドレスを含むことがあります）が記録され、送信の重複防止と履歴の確認にのみ利用します。

利用範囲

店舗の指示の範囲で、フォローメール・レビューお礼メールの送信と、店舗分析のためにのみ利用します。それ以外の目的（自社の広告・営業、他店舗への提供等）には利用しません。

分離と安全管理

  • 店舗ごとに専用のスプレッドシートで保存し、他の店舗から参照できないよう分離しています。
  • アクセスは店舗ごとに発行される認証情報で制御します。
  • 運営の実行ログ（処理の件数・状態・エラーコードが中心）には、購入者情報を直接記録しません。実行ログは14日間保持します。ただし、動作確認（dry_run）時には、Google Apps Script の実行ログに宛先アドレスと件名が一時的に記録されることがあります（保持期間は Google の仕様によります）。

第三者提供

法令に基づく場合を除き、購入者情報を第三者に提供しません。

委託先

GoogleGoogle Apps Script・Google スプレッドシート。システムの実行とデータ保存のため
ロリポップメール送信ブリッジ。メール送信の中継のため

委託先は、上記の目的の範囲でのみ情報を取り扱います。

保存期間と削除

契約期間中は、サービス提供に必要な範囲で保存します。解約後は、利用規約第8条に従い、解約日から30日以内に、運営が削除手続（認証情報・トークン（レビュー取込用トークンを含みます）・ログイン情報の削除）を行い、続けて、店舗専用スプレッドシートとその複製を Google ドライブのゴミ箱へ移します。ゴミ箱の内容は、Google ドライブの仕様により、一定期間（約30日）が経過した後に完全に削除されます。ただし、請求・契約に関する記録（規約への同意の記録を含みます）は、7年間、保持します。

3. レビュー取込用 Chrome 拡張機能「ステップ侍 レビュー取込」

店舗が導入する Chrome 拡張機能「ステップ侍 レビュー取込」（公開者: 株式会社GSD）は、店舗が自らの RMS アカウントでログインした楽天 RMS の「レビューチェックツール」から、レビュー情報の一部を取得し、店舗自身の step-samurai に送信します。取得の主体は店舗自身であり、当社が店舗に代わって RMS にログインすることはありません。

取得する情報（5項目だけ）

レビュータイプレビューの種類の判別
レビュー詳細URLレビューの識別（重複の防止）
評価低評価の除外など、お礼メールの送信判定
投稿時間お礼メールの送信時期の判定
注文番号受注データとの突合

RMS から取得する CSV にはこれ以外の列も含まれますが、拡張機能は解析のうえ上記5項目に絞り、他の列は保存・送信しません。

取得しないもの

  • RMS の ID・パスワード、楽天会員ID・パスワード、Cookie などの認証情報（読み取りも、保存も、送信もしません）
  • 商品名、レビューのタイトル、レビュー本文、フラグ類
  • 購入者の氏名・住所・電話番号・メールアドレスなどの購入者情報
  • 閲覧履歴、位置情報、キー入力、その他の端末・ブラウザの情報

取得する場所

店舗自身がログインした、楽天 RMS のレビューチェックツール（review.rms.rakuten.co.jp）の画面でのみ取得します。それ以外のサイトでは動作しません。

利用目的

  • 店舗自身のレビューお礼メールの送信判定（評価・投稿時期の確認）
  • 店舗専用スプレッドシートの受注データとの突合（注文番号による紐づけ）と、それに基づくレビュー率の集計

これ以外の目的には利用しません。

送信先と委託先

取得した5項目は、店舗自身の step-samurai（Google Apps Script のウェブアプリ）に HTTPS で送信され、店舗専用の Google スプレッドシートに保存されます。委託先は Google（Google Apps Script・Google スプレッドシート）です。この経路では、他の事業者を経由しません。

拡張機能が端末に保存するもの

拡張機能は、ブラウザの保存領域（chrome.storage.local）に、店舗が設定したトークン、前回の同期日時、同期の状態、自動同期を試みた日、同期中の印のみを保存します。レビューの内容（5項目を含みます）は、端末に保存しません。保存されたトークンは、拡張機能の設定画面から削除できます。

安全管理

  • 送信は HTTPS で行います。
  • 送信には、店舗ごとに発行する、レビュー取込専用のトークンを使います。このトークンでは、管理画面にログインしたり、他の操作を行ったりすることはできません。
  • トークンは、当社が失効または再発行できます。失効または再発行されたトークンでは、取り込みはできなくなります。漏えいが疑われる場合は、当社へご連絡ください。

第三者への提供・利用の制限

  • 取得した情報を、第三者に販売・提供しません。
  • 上記の利用目的（レビューの取り込み）と無関係な目的で、使用・転送しません。
  • 信用調査・融資の審査の目的、広告の配信、パーソナライズの目的では使用しません。
  • 人が閲覧するのは、法令で必要な場合、セキュリティ上の調査が必要な場合、または店舗の同意を得てサポートを行う場合に限ります。

拡張機能による Google のユーザーデータの取り扱いは、Limited Use の要件を含む、Chrome ウェブストアのユーザーデータポリシーに従います。

保存期間と解約時の扱い

店舗側のスプレッドシートに保存したレビュー情報の保存期間と削除は、前節「保存期間と削除」のとおり、利用規約第8条に従います。解約時には、レビュー取込用トークンを無効化・削除し、拡張機能からの取り込みを受け付けなくなります。店舗は、解約後、拡張機能を自らのブラウザから削除してください。
