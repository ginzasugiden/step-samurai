利用規約

版 1.1 ／ 施行日 2026年10月25日（改定内容は改定履歴）

この利用規約（以下「本規約」）は、株式会社GSD（銀座杉伝。以下「当社」）が提供する「ステップ侍」（以下「本サービス」）の利用条件を定めるものです。本サービスを申し込む楽天市場の出店店舗（以下「店舗」）は、本規約に同意のうえ、ご利用ください。

第1条（適用）

本規約は、本サービスの提供および利用に関する当社と店舗との間のすべての関係に適用されます。あわせて、プライバシーポリシーおよび当社が本サービス上で案内する各種ルールも、本規約の一部を構成します。

第2条（サービス内容）

本サービスは、店舗の楽天市場の受注データをもとに、店舗名義で次の機能を提供するものです。

  • フォローメール（発送から指定日数後に自動送信）
  • レビューお礼メール（店舗が取り込んだレビュー情報に基づき送信。取り込みの方法は次のとおり）
  • 店舗分析（受注・リピート・レビュー率などの確認画面）
  • クーポン発行機能は準備中です。提供開始時には、追加料金なしで有効化します。

レビュー情報の取り込みは、次の2つの方法のいずれかで、店舗自身が行います。

  1. 店舗が導入する専用の Chrome 拡張機能により、店舗自身がログインした楽天 RMS の「レビューチェックツール」から取得する方法（詳しくは第5条の2）
  2. 店舗が RMS からダウンロードした CSV を、管理画面からアップロードする方法（月1回程度を想定）

いずれの方法でも、レビューの取得を行うのは店舗であり、当社は店舗の RMS ログイン情報（R-Login、楽天会員ID、パスワード、SMS認証を含みます）をお預かりせず、当社が店舗に代わって RMS にログインすることもありません。拡張機能が取得して送信する項目は、レビュータイプ、レビュー詳細URL、評価、投稿時間、注文番号の5項目だけです（商品名、レビューのタイトル・本文、フラグ、購入者の情報は取得しません）。

本サービスが店舗専用スプレッドシートに保存する受注データの項目と用途は、別表のとおりです。当社は、これらを別表およびプライバシーポリシーに記載した目的以外には利用しません。

機能の内容・範囲は、改良のため予告なく変更することがあります。

第3条（申込と成立）

  1. 店舗は、当社が発行する招待コード（有効7日・一回限り）を用いて、当社所定の登録画面から申し込みます。
  2. 登録時に本規約およびプライバシーポリシーに同意いただきます。同意した規約の版と日時は記録されます。
  3. 楽天 RMS への接続テストに成功した時点で申込が完了し、利用契約が成立します。
  4. 実際のお客様向けの送信は、当社が内容を確認し、店舗の稼働開始日に合わせて開始します（それまでは試験運転で、お客様には送信されません）。

第4条（料金・支払・無料トライアル）

  • 利用料は月額9,800円（税別）、初期費用は0円です。
  • 無料トライアルは、申込完了日（RMS 接続テストに成功した日。招待コードの発行日ではありません）の翌日から起算して30日間です（申込完了日当日も送信できます）。この30日目の日（申込完了日の30日後の日）をトライアル終了日とし、その翌日から有料（請求対象）となります。
  • 支払方法は請求書払いです。月末締め、翌月末払いとし、振込手数料は店舗の負担とします。
  • 利用料は日割り計算を行いません。
  • 支払期日から30日を超えても支払の確認が取れない場合、当社は第7条に基づき送信を停止することがあります。
  • 料金を改定する場合は、第10条の手続に従います。

第5条（店舗の責任）

店舗は、次の事項について自らの責任で対応するものとします。

  • RMS のキー（serviceSecret・licenseKey）、あんしんメルアド SMTP の ID・パスワード、および管理画面のログイン情報を適切に管理し、第三者に漏らさないこと。
  • licenseKey の有効期限を把握し、期限前に管理画面「認証情報」から更新すること。期限切れの間は受注の取得およびメール送信ができません。
  • メール文面（件名・本文・署名）の内容、および送信対象・送信時期の設定に責任を持つこと。
  • 楽天市場の各種規約・ガイドライン（レビューを条件とする特典の取扱いを含みます）、特定電子メール法、個人情報保護法その他の法令を遵守すること。
  • お客様から配信停止の申し出があった場合に、管理画面で当該注文を除外する、または当社に連絡すること。
  • 登録内容（店舗連絡先メールアドレス等）を正確・最新に保つこと。
  • 拡張機能をインストールしたブラウザ（および、そのブラウザを使う端末とアカウント）を適切に管理すること。
  • 当社が発行するレビュー取込用トークンを、自らの責任で管理し、第三者に渡さないこと。トークンの漏えいまたはそのおそれがある場合は、直ちに当社へ連絡し、トークンの再発行（旧トークンの失効）を受けること。
  • 楽天市場・RMS の利用規約その他のルールに沿って、レビュー情報を取得すること。

第5条の2（拡張機能）

レビュー取込用の Chrome 拡張機能（以下「拡張機能」）の利用には、次の条件が適用されます。

  • 拡張機能は、店舗が自店の RMS アカウントで利用する場合に限り、使用できます。他の店舗や第三者のために使用してはなりません。
  • 拡張機能が当社へ送信する際に使うトークンは、店舗専用です。他者に渡したり、共有したりしてはなりません。当社は、必要と判断した場合、トークンを無効にできます。
  • 解約または利用停止により店舗の状態が無効（または停止）となった場合、拡張機能からの取り込みは受け付けられなくなります。
  • 拡張機能によるレビューの取得は、店舗の操作および設定（拡張機能のインストール、トークンの設定、RMS へのログイン、同期の操作）に基づいて行われます。拡張機能は、店舗が RMS にログインしている画面からのみ取得し、店舗の ID・パスワードを読み取りません。
  • 取得する項目は、レビュータイプ、レビュー詳細URL、評価、投稿時間、注文番号の5項目だけです。これらは、店舗専用スプレッドシートに送信・保存され、お礼メールの送信判定と、注文との突合（レビュー率の集計を含みます）にのみ利用します。
  • 同期は、RMS のレビューチェックツールを開いたときに1日1回までの自動同期が行われるほか、店舗が拡張機能の画面から手動で実行できます。
  • RMS の画面・データ形式の変更、Chrome ウェブストアの審査・配布の状況、ブラウザの更新などにより、拡張機能が動作しない、または取得が遅れることがあります（第6条）。その間は、CSV アップロードをご利用ください。

取得する情報の詳細は、プライバシーポリシーをご覧ください。

第8条（解約とデータの扱い）

  • 解約を希望する店舗は、解約を希望する月の前月末日までに、ginzasugiden@gmail.com へ申し出てください。解約は、解約を希望する月の末日をもって終了します（例: 11月末で解約する場合は、10月31日までにお申し出ください）。
  • 解約日をもって、当社は店舗の状態を無効（disabled）にし、送信を終了します。無効にした店舗については、拡張機能からのレビュー取り込みを受け付けません。レビュー取込用トークンは、当社が無効化し、下記の削除手続の中で削除します。

    1. 削除（purge）: 暗号化して保存していた認証情報（RMS キー・SMTP 情報）、アクセストークン（レビュー取込用トークンを含みます）、ログイン情報を削除します。この際、店舗専用スプレッドシート（受注データ、レビュー情報等）は、削除に先立って複製を作成し、元のシートは名称を変更して保管します。
    2. 最終削除: 名称を変更した専用スプレッドシートと、削除の際に作成した複製（専用スプレッドシートの複製と、店舗に関する管理情報の複製）を、Google ドライブのゴミ箱へ移します。
  • 当社は解約日から30日以内に、本サービスの専用シート、その複製、暗号化された認証情報およびトークンを削除します（削除したデータはクラウドの仕組み上、最大30日間ゴミ箱に残った後に完全に消去されます）。
  • ゴミ箱へ移したデータは、Google ドライブの仕様により、最大30日間が経過した後に完全に削除されます。それまでの間は、ゴミ箱の中にデータが残ります。当社は、この期間中も、ゴミ箱のデータを本サービスの提供その他の目的には利用しません。
  • 店舗は、解約後、拡張機能を自らのブラウザから削除（アンインストール）してください。
  • ただし、請求・契約に関する記録（規約への同意の記録を含みます）は、7年間、保持します。

別表（受注データの項目と用途）

店舗専用スプレッドシートの「受注」の項目と、その主な用途です（項目名のみを示し、実際のデータは記載しません）。これらは、店舗の委託を受けて、本サービスの提供（メール送信・店舗分析）の範囲でのみ利用し、目的外には使いません。

項目区分主な用途
order_number（注文番号）識別子注文の一意キー、レビュー・送信履歴との突合
order_date / order_datetime（受注日 / 受注日時）個人を直接識別しない項目集計期間、購入回数の計算、時間帯別集計
buyer_key（購入者識別キー）個人情報（購入者の識別）同一購入者の判定、購入回数、送信履歴、クーポン判定
masked_email（メールアドレス）個人情報（メールアドレス。通常は楽天のあんしんメルアドが発行するマスクアドレス）メールの宛先、新規／リピートの判定
buyer_name（注文者氏名）個人情報（氏名）メール本文の宛名
prefecture（都道府県）個人情報の一部都道府県別の集計
item_code / item_name（商品コード / 商品名）個人を直接識別しない項目商品別の集計
amount / goods_price（金額 / 商品金額）個人を直接識別しない項目売上集計、月次レポート
units（点数）個人を直接識別しない項目点数の集計
purchase_count（購入回数）派生項目リピート判定、クーポン条件
ship_date（発送日）個人を直接識別しない項目フォロー・お礼メールの送信時期の判定
status（ステータス）個人を直接識別しない項目送信対象の判定（キャンセルの除外）、集計の母集団
review_linked（レビュー紐づけ）個人を直接識別しない項目レビュー率、クーポン条件
coupon_shop_price / coupon_codes（クーポン額 / クーポンコード）個人を直接識別しない項目クーポン利用の集計

保存しないもの: 番地を含む住所、電話番号、郵便番号は保存しません。

このほか、メール送信履歴（sends）には、送信の識別子や注文番号に加え、宛先に由来する識別子（メールアドレスを含むことがあります）が記録されます。これは、送信の重複防止と履歴の確認のためにのみ利用します。
