# ストア用スクリーンショットの撮り方

## 仕様

- サイズ: **1280x800**（または 640x400）。形式は PNG（24bit・透過なし）または JPEG。
- 枚数: 1〜5 枚（3〜4 枚を推奨）。日本語 UI のまま撮る。
- ストアのプロモーション画像（小 440x280）は任意。

## 撮るべき画面

1. **ポップアップ（正常）**: 「正常です」と最終同期日時が表示された状態。
2. **ポップアップ（要対応）**: 例として「RMS のレビューチェックツールを開いてから、もう一度押してください」の案内（未ログイン・タブなしの状態）。
3. **設定画面**: 店舗トークン欄（保存済みの表示は `sse_…xxxx` のマスク表示）、「送信テスト」で「接続OK」が出た状態。
4. **設定画面の下部**: 取得する5項目と、権限の説明、プライバシーポリシーへのリンク。

ブラウザの外枠（ツールバー）を含める場合も、背景は無地にし、1280x800 に収める。

## 手順

1. ダミー店舗（テスト用テナント）のトークンを発行し、`chrome://extensions` →「パッケージ化されていない拡張機能を読み込む」で `extension/` を読み込む。
2. 設定画面でトークンを保存し、「送信テスト」を押す（dry_run のため何も書き込まれない）。
3. ブラウザのウィンドウを 1280x800 にして撮影する（開発者ツールのデバイスツールバーか、OS のスクリーンショットでトリミング）。
4. 撮影後、ファイルの寸法が 1280x800 であることを確認する。

## 個人情報・機密を映さない注意

- 実店舗のトークン（平文）、実の注文番号、実のレビュー詳細 URL、店舗名、メールアドレス、購入者情報を**絶対に映さない**。テスト用テナントと架空の値だけを使う。
- トークンの入力欄は `type=password` のため入力中は伏せ字になるが、保存済み表示（先頭 `sse_` と末尾4文字）も、テスト用のものだけを映す。
- RMS の画面（レビュー一覧・店舗名・ログイン中のアカウント表示）を映さない。必要ならポップアップと設定画面だけを撮る。
- ブラウザのブックマークバー・他のタブ・プロフィール画像・通知に個人情報が映っていないか、保存前に拡大して確認する。
