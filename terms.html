利用規約

版 1.0 ／ 施行日 2026年10月23日

この利用規約（以下「本規約」）は、株式会社GSD（銀座杉伝。以下「当社」）が提供する「ステップ侍」（以下「本サービス」）の利用条件を定めるものです。本サービスを申し込む楽天市場の出店店舗（以下「店舗」）は、本規約に同意のうえ、ご利用ください。

第1条（適用）

本規約は、本サービスの提供および利用に関する当社と店舗との間のすべての関係に適用されます。あわせて、プライバシーポリシーおよび当社が本サービス上で案内する各種ルールも、本規約の一部を構成します。

第2条（サービス内容）

本サービスは、店舗の楽天市場の受注データをもとに、店舗名義で次の機能を提供するものです。

  • フォローメール（発送から指定日数後に自動送信）
  • レビューお礼メール（店舗がアップロードした RMS「レビューチェックツール」の CSV に基づき送信。月1回程度のアップロードを想定）
  • 店舗分析（受注・リピート・レビュー率などの確認画面）
  • クーポン発行機能は準備中です。提供開始時には、追加料金なしで有効化します。

機能の内容・範囲は、改良のため予告なく変更することがあります。

第3条（申込と成立）

  1. 店舗は、当社が発行する招待コード（有効7日・一回限り）を用いて、当社所定の登録画面から申し込みます。
  2. 登録時に本規約およびプライバシーポリシーに同意いただきます。同意した規約の版と日時は記録されます。
  3. 楽天 RMS への接続テストに成功した時点で申込が完了し、利用契約が成立します。
  4. 実際のお客様向けの送信は、当社が内容を確認し、店舗の稼働開始日に合わせて開始します（それまでは試験運転で、お客様には送信されません）。

第4条（料金・支払・無料トライアル）

  • 利用料は月額9,800円（税別）、初期費用は0円です。
  • 無料トライアルは、申込完了日（RMS 接続テストに成功した日。招待コードの発行日ではありません）から30日後の日（トライアル終了日）までで、最大30日間です。トライアル終了日の翌日から有料（請求対象）となります。
  • 支払方法は請求書払いです。月末締め、翌月末払いとし、振込手数料は店舗の負担とします。
  • 利用料は日割り計算を行いません。
  • 支払期日から30日を超えても支払の確認が取れない場合、当社は第7条に基づき送信を停止することがあります。
  • 料金を改定する場合は、第10条の手続に従います。

第5条（店舗の責任）

店舗は、次の事項について自らの責任で対応するものとします。

  • RMS のキー（serviceSecret・licenseKey）、あんしんメルアド SMTP の ID・パスワード、および管理画面のログイン情報を適切に管理し、第三者に漏らさないこと。
  • licenseKey の有効期限を把握し、期限前に管理画面「認証情報」から更新すること。期限切れの間は受注の取得およびメール送信ができません。
  • メール文面（件名・本文・署名）の内容、および送信対象・送信時期の設定に責任を持つこと。
  • 楽天市場の各種規約・ガイドライン（レビューを条件とする特典の取扱いを含みます）、特定電子メール法、個人情報保護法その他の法令を遵守すること。
  • お客様から配信停止の申し出があった場合に、管理画面で当該注文を除外する、または当社に連絡すること。
  • 登録内容（店舗連絡先メールアドレス等）を正確・最新に保つこと。

第6条（免責）

  • 楽天市場・RMS・各種 API の仕様変更、提供停止、障害、あんしんメルアド等の仕様変更によって本サービスの全部または一部が利用できなくなった場合、当社はこれにより生じた損害について責任を負いません。
  • メールは、あんしんメルアド経由の送信を含め、受信側の設定や通信事情等により不達・遅延となることがあります。当社は到達を保証しません。
  • 当社は、本サービスの提供にあたり合理的な注意を払いますが、無停止・無誤謬であることを保証しません。メンテナンスや障害対応のため、予告なく一時停止することがあります。
  • 店舗が設定した文面・設定、または店舗の第三者（お客様等）との間の紛争については、店舗の責任で解決するものとします。

第7条（利用停止）

店舗が本規約に違反した場合、登録内容に虚偽があった場合、RMS の認証情報が無効となった場合その他、当社が本サービスの提供を継続しがたいと判断した場合には、当社は本サービスの全部または一部の提供を停止できます。停止は、原則として事前に店舗へ通知したうえで行います。

次のいずれかに該当するときに限り、当社は事前の通知なく停止できます。

  • 不正利用またはその疑いがある場合
  • セキュリティ上の緊急の必要がある場合
  • 楽天からの要請があった場合
  • 支払期日から30日を超えて利用料の支払が確認できない場合

利用停止により生じた損害について、当社は責任を負いません。

第8条（解約とデータの扱い）

  • 解約を希望する店舗は、解約を希望する月の前月末日までに、ginzasugiden@gmail.com へ申し出てください。解約は、解約を希望する月の末日をもって終了します（例: 11月末で解約する場合は、10月31日までにお申し出ください）。
  • 解約日をもって、当社は店舗の状態を無効（disabled）にし、送信を終了します。
  • 解約日から30日以内に、店舗専用スプレッドシート（受注データ等）、その複製、暗号化して保存していた認証情報（RMS キー・SMTP 情報）、およびアクセストークンを削除します。
  • ただし、請求・契約に関する記録（規約への同意の記録を含みます）は、法令上必要な期間、保持します。
  • すでに送信済みのメールは取り消せません。

第9条（損害賠償の上限）

当社が本サービスに関して店舗に対して負う損害賠償責任は、当社に故意または重過失がある場合を除き、損害発生の直近3か月間に当社が店舗から支払を受けた利用料の総額を上限とします。また、逸失利益その他の間接損害・特別損害については、当社に故意または重過失がある場合を除き、責任を負いません。

第10条（規約の変更）

当社は、本規約を変更することがあります。変更する場合は、効力発生日の相当期間前に、本サービス上またはメールで店舗に周知します。変更後に店舗が本サービスを利用した場合、変更後の規約に同意したものとみなします。

第11条（準拠法・管轄）

本規約は日本法に準拠します。本サービスに関して当社と店舗の間で紛争が生じた場合は、東京地方裁判所を第一審の専属的合意管轄裁判所とします。
