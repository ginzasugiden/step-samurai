## 3. 申込から稼働までの流れ
1. お問い合わせ（ginzasugiden@gmail.com）
2. 運営から案内・準備物の確認
3. 運営から **招待コード** を受け取る（有効7日・一回限り）
4. `https://step-samurai.ginzasugiden.com/` の「お申し込み」に招待コードを入力し、案内に沿って入力・規約とプライバシーポリシーに同意（約15分）。楽天への接続テストに成功すると登録完了（失敗した場合は保存されません。キー・申請状況をご確認ください）。ここから無料トライアルが始まります
5. 運営が内容を確認し、メール文面のプレビューを案内
6. 試験運転（dry_run）: お客様には送信せず動作を確認。管理画面「テスト送信」で店舗連絡先メール宛に文面確認ができます
7. 稼働開始: 稼働開始日以降に発送した注文から自動送信
8. 無料トライアル終了後、請求書でご案内

所要日数の目安: 登録は約15分。運営の確認から稼働開始まで、通常3〜7営業日が目安です。

## 3-2. メール設定画面の使い方（v1.3〜）
- 画面: `https://step-samurai.ginzasugiden.com/webui/settings.html`（管理画面と同じ店舗ID・パスワードでログイン）。
- **フォローメール**: 出荷日から何日後に送るか（1〜30の整数）と、件名（120字以内）・本文（5000字以内）を編集できます。
- **レビューお礼**: ★の数で最大3段階に分けられます（例: ★5-1 / ★5-3・★2-1 / ★5-4・★3・★2-1）。★1〜5が重複・抜けなくどれか1つの段階に入るよう、区切りは画面のプルダウンから選びます。段階ごとに「送る／送らない」・件名・本文・クーポンURL・プレビュー・テスト送信（店舗の登録メール宛て）があります。
- 使える変数: `{{buyer_name}}` `{{shop_name}}` `{{ship_date}}` `{{shop_signature}}` `{{review_url}}` `{{rating}}`（レビューの★）`{{coupon_url}}`（その段階のクーポンURL。空欄ならその行ごと送りません）。`{coupon_url}` `{rating}` は単括弧でも書けます。未定義の変数は保存時に警告します。
- **クーポンURL**: 段階ごとに任意で登録できます（https の *.rakuten.co.jp のみ）。段階数を減らしても使われなくなった段階のURLは保持され（画面ではグレー表示）、送信には使われません。
- **【重要】クーポンとガイドライン**: ★の数によってクーポンの有無や内容を変えると、楽天市場のレビューガイドラインに抵触するおそれがあります。設定内容は店舗様の責任で管理してください。初めて段階ごとに異なるクーポンURLを保存するときは確認が出て、同意した日時と店舗が記録されます。
- **利用規約 v1.3**: レビュー評価に応じたメール文面・クーポン等の設定内容と、それが楽天市場の規約・ガイドラインに適合することについては利用店舗が責任を負います。既存の店舗は次回ログイン時に同意を求められます。同意するまで段階別クーポンは保存できません（メール送信は止まりません）。
- レビュー段階の設定が未保存の間は、レビューお礼メールは送られません。
- **取り込み状況**タブ: 最後に取り込めた日時・拡張機能のバージョン・48時間超の警告を確認できます。

### 自動取り込み（拡張機能 v1.1.0〜）の前提
- **Chrome が起動していて、楽天 RMS にログインしている間**、3時間ごとに自動でレビューを取り込みます（インストール直後と Chrome 起動時にも1回）。ログイン情報は保存されません。
- 未ログイン・失敗のときは、拡張アイコンに赤い「!」（48時間超は「48h」）、デスクトップ通知、RMS 画面上部の帯でお知らせします。店舗画面には、最終成功から6時間超で赤い帯が出ます。
- 警告メール（件名【要対応】）: 初回検知→24時間後→48時間後（運営にも）→以降1日1回。対処は Chrome を起動 → RMS にログイン → 拡張アイコンから「今すぐ取り込む」。正常に戻ると警告はすべて解除されます。
- 登録から24時間たっても拡張機能から連絡がない場合は、インストール案内のメールをお送りします。

## 4. ご利用上の制約・注意
- **クーポン自動発行は準備中**です（現在のご提供はフォローメール・レビューお礼メール・店舗分析）。クーポンは提供開始時に追加料金なしで有効化します。
- レビューを条件にするクーポン等は、楽天のガイドラインに従い投稿者全員に一律で運用してください。
- レビューお礼メールは評価が低い（既定：星3未満）場合は自動送信せず、個別対応をおすすめします（基準は運営の設定によります）。フォローメールは評価とは別に、発送後の指定日数で送信されます。
- レビューの取り込み: 次のどちらかで、店舗自身が行います。(1) Chrome 拡張機能「ステップ侍 レビュー取込」（運営から届く限定公開リンクから追加し、運営から届くトークンを設定。RMS のレビューチェックツールを開くと1日1回まで自動で同期）。(2) 管理画面（店舗ログイン →「レビュー取込」タブ）で、RMS「レビューチェックツール」の CSV を定期的に（週1回を推奨）アップロード（拡張機能を入れられない場合の方法）。手順は guide.html の「レビューの取り込み」。いずれも RMS のログイン情報はお預かりしません。
- テストメール: お客様宛はあんしんメルアド（マスクアドレス）経由のため、一般のメールアドレスには届きません。管理画面「テスト送信」は店舗連絡先メール宛にのみ送信されます。
- 受注データはお客様専用のスプレッドシートに保存され、他店舗からは参照できません。
- serviceSecret / licenseKey / SMTP パスワードは暗号化して保存しますが、送信のためにシステムが復号して利用します。
- 解約時は、店舗の状態を無効（disabled）にし、暗号化認証情報・トークン（レビュー取込トークンを含む）を削除、スプレッドシートは運営が複製のうえ Google ドライブのゴミ箱へ移します（ゴミ箱の内容は Drive の仕様により約30日後に完全削除）。これらは解約日から30日以内に行います（利用規約第8条）。
- 配信停止のご要望があった注文は、管理画面の「除外注文」タブに注文番号を登録してください（登録した注文にはフォロー・お礼メールを送りません。解除もできます）。運営へのご連絡でも対応します。すでに送信済みのメールは取り消せません。
- 1回（毎時）の実行で送信するメールは最大50件です。多数の注文がたまっている場合は、数回に分けて順次送信します。
- 稼働開始希望日は、お申し込み日以降の日付のみ指定できます。
