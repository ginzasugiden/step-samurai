ご利用開始ガイド

ステップ侍は、楽天市場の受注データをもとに、発送後のフォローメールとレビューお礼メールを店舗名義で自動送信するサービスです。このページの準備物を揃えると、登録は約15分で終わります。

お客様のログイン情報（R-Login・楽天会員ID・パスワード）はお預かりしません。

1. 準備物チェックリスト

  • 店舗URL https://www.rakuten.co.jp/○○/ に対応する RMS の店舗ID
  • 楽天ペイ受注API の利用申請後に発行（手順は次の節）。有効期限があります
  • RMS の画面に表示される期限日を控えます
  • RMS に登録済みのもの。フォローメールの差出人になります
  • 店舗名義でお客様のマスクアドレスへ送るために必要です
  • 開始日以降に発送した注文だけが対象です（お申し込み日以降の日付を指定）。日数の目安は発送後5日
  • 8文字以上。登録時に設定します

2. RMS での取得手順

serviceSecret / licenseKey

  1. RMS の「店舗設定」→「WEB API」を開きます。
  2. 楽天ペイ受注API の利用申請をします。
  3. ライセンスキーを発行し、表示された serviceSecret と licenseKey、有効期限を控えます。

licenseKey には有効期限があります。RMS の画面に表示される期限日を登録し、期限前に管理画面「認証情報」で更新してください（期限30日前に運営者へ通知し、運営者から更新のお願いを連絡します）。期限が切れると、受注の取得とメール送信ができなくなります。

あんしんメルアド SMTP

  1. RMS の「メール」→「あんしんメルアドサービス」を開きます。
  2. SMTP 設定で、ID とパスワードを発行して控えます。

画面名はRMSの更新で変わることがあります。見つからない場合は、RMSマニュアルを参照してください。利用可にするAPIは、楽天ペイ受注API（必須）だけで足ります。不要なAPIは利用可にしないでください。

3. 申込から稼働までの流れ

  1. お問い合わせ: ginzasugiden@gmail.com へご連絡ください。
  2. ご案内: 運営からサービスの案内と準備物の確認が届きます。
  3. 招待コード受領: 運営が招待コードを発行します（有効7日・一回限り）。
  4. 登録（約15分）: 登録ページ（トップの「お申し込み」からも進めます）で、店舗情報・RMS キー・SMTP を入力し、規約とプライバシーポリシーに同意します。楽天への接続テストに成功すると登録完了です。ここから無料トライアル（申込完了日の翌日から起算して30日間）が始まります。
  5. 運営の確認・プレビュー: 運営が送信前の文面をメールでお送りします（ご確認・修正のご希望を受けて稼働開始します）。
  6. 試験運転（dry_run）: お客様には送信せず、動作を確認します。この間、管理画面の「テスト送信」（フォローメールのみ・宛先は店舗連絡先メール固定）も実際には送信されません。
  7. 稼働開始: 稼働開始日以降に発送した注文から、自動送信が始まります。
  8. 無料トライアル → 請求: トライアル終了日（申込完了日の30日後の日）の翌日から請求対象となり、請求書でご案内します（月末締め翌月末払い）。

所要日数の目安: 登録は約15分。運営の確認から稼働開始までは、通常3〜7営業日が目安です（状況により前後します）。

招待コードをお持ちの方は登録へお問い合わせ

4. レビューの取り込み

レビューお礼メールは、レビュー情報を取り込んだ注文に対して送信されます。取り込みの方法は、次の2つから選べます（どちらも店舗自身が行います）。

方法1: Chrome 拡張機能「ステップ侍 レビュー取込」

パソコンの Chrome が使える場合の方法です。楽天 RMS のレビューチェックツールを開くと、1日1回まで自動で取り込まれます。

拡張機能の入れ方

  1. 運営からメールで届く限定公開のリンクを、Chrome で開きます。
  2. 「Chrome に追加」を押して、確認画面で追加します。

トークンの設定

  1. 運営からメールで届くトークン（sse_ から始まる文字列）をコピーします。トークンは店舗専用です。他の方には渡さないでください。
  2. Chrome の拡張機能のアイコンを右クリックし、「オプション」を開きます。
  3. 入力欄にトークンを貼り付けて「保存」を押します。
  4. 「送信テスト」を押し、「接続OK」と表示されれば設定は完了です。

同期の使い方

  • RMS にログインして「レビューチェックツール」を開くと、自動で同期されます（自動同期は1日1回までです）。
  • すぐに同期したいときは、拡張機能のアイコンを押して、「今すぐ同期」を押してください（RMS のレビューチェックツールを開いたうえで押します）。
  • 最終同期から3日を超えると、拡張機能のアイコンのバッジに「!」が表示されます。RMS のレビューチェックツールを開いてください。

取得する項目

レビュータイプ、レビュー詳細URL、評価、投稿時間、注文番号の5項目だけです。商品名・レビューのタイトルと本文・購入者の情報は取得しません。RMS の ID・パスワードはお預かりしません（拡張機能も読み取りません）。詳しくはプライバシーポリシー・利用規約第5条の2をご覧ください。

うまくいかないとき

拡張機能のアイコンを押すと、現在の状態と対処が表示されます。

表示（バッジ）対処
設定トークンが未設定です。「オプション」でトークンを保存してください。
ログRMS にログインしていません。RMS にログインしてレビューチェックツールを開き、もう一度同期してください。
鍵トークンが正しくない、または無効になっています。「オプション」でトークンを確認してください。無効になっている場合は、運営に再発行を依頼し、新しいトークンを保存してください。
要更新RMS から取得したデータの形式が想定と違うため、何も送らずに停止しました。RMS の画面仕様が変わった可能性があります。拡張機能の更新をお待ちください（その間は方法2をご利用いただけます）。運営にもご連絡ください。
ERR画面に表示される案内に従ってください。続く場合は運営にご連絡ください。
!最終同期から3日を超えています。RMS のレビューチェックツールを開いて同期してください。

通信の失敗など一時的な失敗は、次回の同期に持ち越されます。RMS の仕様変更やブラウザの更新などにより、拡張機能が動作しないことがあります。解約後は、拡張機能を Chrome から削除してください。

方法2: CSV をアップロードする

拡張機能を入れられない場合や、拡張機能が使えない間は、CSV のアップロードで取り込めます。月1回程度が目安です。

  1. RMS の「レビューチェックツール」から、レビューの CSV をダウンロードします。
  2. 管理画面（店舗ログイン）の「レビュー取込」タブで、そのファイルを選びます（列の順番や余分な列は自動で判定されます）。
  3. 「内容を確認」を押し、問題がなければ「取り込む」を押します。同じ CSV を何度取り込んでも重複しません。

取り込み後、お礼メールの条件（評価など）を満たす注文へ、毎時の処理で自動送信されます。

5. よくある質問

自社のGmailにテストメールが届きません
お客様宛のメールは、楽天のあんしんメルアド（マスクアドレス）経由で送られるため、一般のメールアドレス宛には届きません。管理画面の「テスト送信」はフォローメールのみで、店舗連絡先メールアドレス宛にのみ送信されます（他の宛先には送れません）。試験運転（dry_run）の間は送信されません。送信前の文面は、運営がメールでお送りします。
過去のお客様に一斉送信されませんか
されません。稼働開始日以降に発送した注文だけが対象です。それ以前の注文には送りません。
低評価のレビューをくださったお客様にもお礼メールが届きますか
レビューお礼メールは、評価が低いもの（既定は星3未満）には自動送信しません。内容を確認して個別に対応することをおすすめします。基準は運営の設定によります。なお、発送後のフォローメールは評価とは別に、発送後の指定日数で送信されます。
レビューお礼メールはどう届きますか
レビュー情報を取り込むと、条件を満たす注文へ自動で送信されます。取り込みは、Chrome 拡張機能（RMS のレビューチェックツールを開くと1日1回まで自動で同期）か、管理画面「レビュー取込」タブでの CSV アップロード（月1回程度）のどちらかで行います。手順はレビューの取り込みをご覧ください。
クーポンは使えますか
クーポン発行機能は準備中です。現在は、フォローメール・レビューお礼メール・店舗分析をご提供しています。クーポンは、提供開始時に追加料金なしで有効化します。
licenseKey の更新はどうすればよいですか
RMS で新しいキーを発行し、管理画面の「認証情報」から更新してください。有効期限の30日前に運営者へ通知が届き、運営者から更新のお願いをご連絡します。
メールを止めてほしいお客様がいます
管理画面の「除外注文」タブに注文番号を登録してください（登録した注文にはフォロー・お礼メールを送りません。解除もできます）。または運営へご連絡ください。すでに送信済みのメールは取り消せません。
解約したい
解約を希望する月の前月末日までに、ginzasugiden@gmail.com へお申し出ください（例: 11月末で解約する場合は10月31日まで）。解約日は解約希望月の末日です。解約後のデータの扱いは利用規約第8条をご覧ください。

1回（毎時）の実行で送信するメールは最大50件です。多数の注文がたまっている場合は、数回に分けて順次送信します。
