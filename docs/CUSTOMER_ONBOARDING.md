# ステップ侍 ご利用開始ガイド（お客様向け）

楽天市場の受注データをもとに、発送後のフォローメールとレビューお礼メールを店舗名義で自動送信するサービスです。

## 1. 料金
- 月額 9,800円 / 初期費用 0円
- 無料トライアル 最大30日（お申し込み完了日から起算）
- お支払いは **請求書払い**（担当者よりご案内）。クレジットカード決済は準備中です。
- トライアル終了後、お支払いの確認が取れない場合は送信を停止します（データは保持されます）。

## 2. 事前にご準備いただくもの
| 準備物 | 取得場所（RMS） | 備考 |
|---|---|---|
| 店舗ID（sid・数字） | 店舗URL `https://www.rakuten.co.jp/○○/` に対応する RMS 店舗ID | |
| serviceSecret / licenseKey | 店舗設定 → WEB API → 楽天ペイ受注API の利用申請 → ライセンスキー発行 | **licenseKey は1年で失効**。期限前に管理画面から更新 |
| 店舗連絡先メールアドレス | 店舗設定 → 基本情報 | フォローメールの差出人。RMS登録済みのものに限ります |
| あんしんメルアド SMTP ID / パスワード | メール → あんしんメルアド SMTP設定 | 店舗名義でお客様のマスクアドレスへ送るために必要 |
| 稼働開始希望日 / フォローまでの日数 | ― | 開始日以降に発送した注文だけが対象（過去のお客様へ一斉送信しません） |

楽天へのログイン情報（R-Login・楽天会員ID・パスワード）は **お預かりしません**。

## 3. お申し込みの流れ
1. 運営から **招待コード** を受け取る（有効7日・一回限り）
2. `https://step-samurai.ginzasugiden.com/` の「お申し込み」に招待コードを入力し、案内に沿って上記を入力
3. 楽天への接続テストに成功すると登録完了（失敗した場合は保存されません。キー・申請状況をご確認ください）
4. 運営が内容を確認後、稼働開始日から送信が始まります

## 4. ご利用上の制約・注意
- **クーポン自動発行は準備中**です（現在のご提供はフォローメール・レビューお礼メール・店舗分析）。
- レビューを条件にするクーポン等は、楽天のガイドラインに従い投稿者全員に一律で運用してください。
- レビューお礼メールは評価が低い（既定：星3未満）場合は自動送信せず、個別対応をおすすめします。
- レビューの取得は運営側の連携またはレビューCSVの取り込みで行います。
- 受注データはお客様専用のスプレッドシートに保存され、他店舗からは参照できません。
- serviceSecret / licenseKey / SMTP パスワードは暗号化して保存しますが、送信のためにシステムが復号して利用します。
- 解約時は暗号化データ・トークンを削除し、スプレッドシートは譲渡または削除します。
- 配信停止のご要望があった注文は、管理画面の設定（除外注文）または運営へご連絡ください。
