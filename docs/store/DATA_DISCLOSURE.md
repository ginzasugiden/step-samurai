# データ使用の開示（Chrome ウェブストア「プライバシーへの取り組み」回答案）

## 1. 取得するデータ（5項目だけ）

| 項目 | 内容 | 用途 |
|---|---|---|
| レビュータイプ | レビューの種類 | レビューの種類の判別 |
| レビュー詳細URL | レビューの詳細ページの URL | レビューの識別（重複防止） |
| 評価 | 星の数 | 低評価の除外など、お礼メールの送信判定 |
| 投稿日時 | レビューの投稿日時 | お礼メールの送信時期の判定 |
| 注文番号 | 該当する注文の番号 | 受注データとの突合 |

RMS の CSV には他の列も含まれるが、解析後すぐに上記の5項目だけに絞り、他は破棄する（変数にも、ログ・storage・メッセージにも残さない）。

## 2. 取得しないもの

- 楽天 RMS の ID・パスワード・Cookie・認証情報
- 商品名、レビューのタイトル、レビュー本文、フラグ類
- 購入者の氏名・住所・電話番号・メールアドレスなどの購入者情報
- 閲覧履歴、位置情報、キー入力、その他の端末・ブラウザの情報

## 3. 送信先と保存

- 送信先は、店舗自身の step-samurai（Google Apps Script のウェブアプリ。店舗専用スプレッドシートに記録）のみ。第三者へは送信しない。
- 拡張機能内に保存するのは、トークン・前回の同期日時・状態コード・自動同期の試行日・同期中フラグのみ（`chrome.storage.local`）。レビューのデータは保存しない。
- 送信は HTTPS。送信には店舗ごとの専用トークン（レビュー取込専用）を使う。

## 4. 利用の制限（ストアのユーザーデータポリシーへの適合）

- ユーザーデータを第三者に販売しない。
- 拡張機能の単一目的（レビューの取込）と無関係な目的で使用・転送しない。
- 信用調査・融資の審査目的で使用・転送しない。
- 広告の配信、パーソナライズ目的で使用しない。
- 人による閲覧は、法令で必要な場合・セキュリティ上の調査・サポートで店舗が同意した場合に限る。

## 5. 「ユーザーデータ」チェック項目への回答案

ストアのフォームの項目名は変更されうるため、提出時の実画面に合わせて選ぶこと。

| 区分 | 回答 | 理由 |
|---|---|---|
| 個人を特定できる情報 | 収集しない（チェックしない） | 氏名・住所・メール等は取得しない。注文番号は店舗の業務データ。 |
| 健康に関する情報 | 収集しない | |
| 財務情報および支払い情報 | 収集しない | 金額・決済情報は取得しない。 |
| 認証情報 | 収集しない | RMS の ID・パスワード・Cookie は読み取らない。店舗トークン（拡張連携トークン）は店舗が自分で設定し、送信先への認証にのみ使う。 |
| 個人的なやり取り | 収集しない | |
| 位置情報 | 収集しない | |
| ウェブ履歴 | 収集しない | |
| ユーザーのアクティビティ | 収集しない | |
| ウェブサイトのコンテンツ | **収集する（チェックする）** | RMS のレビューチェックツールのレビュー情報のうち、上記5項目だけ。 |

### 3つの宣言（認証）

- [x] 承認された用途以外で、ユーザーデータを第三者に販売または転送しない
- [x] 単一目的と無関係な目的で、ユーザーデータを使用または転送しない
- [x] 信用力の判断や融資の目的で、ユーザーデータを使用または転送しない

## 6. 運用上の注意

- 取得項目を増やす場合は、実装より先に本書・`PERMISSIONS.md`・プライバシーポリシー（privacy.html）を更新し、ストアの再審査に備える。
