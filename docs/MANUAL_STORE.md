# ステップ侍 ご利用マニュアル（店舗様向け）

ステップ侍は、楽天市場のご注文に対して「発送後のフォローメール」を自動送信し、受注・レビュー・メール送信の状況を分析画面で確認できるサービスです。
**貴店のログイン情報（R-Login・楽天会員ID・パスワード）は一切お預かりしません。** 必要なのは楽天RMSで発行する「APIキー」と「SMTP設定」だけです。

---

## 1. 事前準備（RMSでの操作・所要15分）

### 1-1. WEB API の利用申請とキー発行
1. RMS メインメニュー →「拡張サービス一覧」→「WEB API サービス」→「利用設定」
2. 「アプリ追加」で **ステップ侍** 用のアプリを作成（アプリ名は任意）
3. 「利用可能API一覧」で、以下の API を **利用可** にしてください

| API | 用途 | 必須 |
|---|---|---|
| **楽天ペイ受注API（RakutenPayOrderAPI）** `searchOrder` / `getOrder` | ご注文の取得（発送日・お客様のマスクアドレス・購入回数） | **必須** |
| **クーポンAPI（CouponAPI）** `coupon.issue` / `coupon.get` | レビュー特典クーポンの自動発行（今後提供） | 推奨 |
| **ライセンス管理API（LicenseManagementAPI）** `license.expiryDate` | licenseKey 期限の自動確認（今後提供） | 推奨 |

上記以外（商品API・在庫API・キャビネットAPI 等）は不要です。**貴店のデータを守るため、不要なAPIは利用可にしないでください。**

4. 「ライセンスキー発行」を押し、表示された **serviceSecret** と **licenseKey**、**有効期限** を控えてください（licenseKey は1年ごとに再発行が必要です）

### 1-2. あんしんメルアド SMTP 設定
1. RMS →「メール」→「あんしんメルアドサービス」→「SMTP設定」
2. SMTP の **ID** と **パスワード** を発行して控えてください
   （お客様のマスクアドレス宛には、貴店の店舗連絡先メールを差出人にした場合のみ届きます）

### 1-3. 控えるもの
- 店舗ID（sid）… 数字。RMS 右上の店舗名横、または店舗URL設定に表示
- 店舗連絡先メールアドレス（RMS「基本情報」に登録のもの）

---

## 2. 登録（ブラウザで5分）

1. 運営者から届いた **登録URL（招待コード入り）** を開く。届いていない場合は `https://step-samurai.ginzasugiden.com/webui/onboard.html` を開き、API のURL と招待コードを入力
2. 店舗情報・APIキー・SMTP・運用の希望（フォロー日数・稼働開始希望日）を入力
3. 「接続テストして登録」→ 楽天への接続に成功すると登録完了
4. 表示された **アクセストークン** を保管してください（**二度と表示されません**。運営者も見られません）

入力したキー・パスワードは暗号化して保管され、運営者の画面・シート・ログには表示されません（システムが楽天へアクセスするために内部では復号します）。

---

## 3. 管理画面の使い方（`webui/index.html`）

API のURL とアクセストークンでログインします。

| タブ | できること |
|---|---|
| 設定 | フォローメールを送る「発送後日数」、クーポン有効期間、メール署名 |
| 文面 | フォローメール・クーポンメールの件名/本文。`{{buyer_name}}` `{{shop_name}}` `{{ship_date}}` などの差し込み変数が使えます |
| テスト送信 | 現在の文面を **貴店の店舗メール宛** に送って確認（他の宛先には送れません） |
| 履歴 | 直近50件の送信・クーポン発行 |
| レビュー取込 | RMS「レビューチェックツール」の CSV を選ぶだけで取込。週1回を目安に |
| 認証情報 | licenseKey の年次更新、SMTP の変更 |

**稼働開始**は、運営者が内容を確認したうえで行います（それまでは「dry_run」状態で、実際のお客様には送信されません）。

---

## 4. 店舗分析（`webui/analytics.html`）

同じトークンでログイン。期間を選んで、受注件数・売上（RMS準拠）・新規/リピート・時間帯別・曜日別・レビュー率・評価分布・クーポン利用率・商品別/都道府県別を表示。CSV でダウンロードもできます。
数字は「受注日基準・キャンセル除外」です。RMS の店舗カルテとほぼ一致しますが、集計定義の違いで数円〜数%の差が出ることがあります。

---

## 5. 運用上のお願い

- **レビューを条件にしたクーポン**は、楽天のガイドラインに従い「投稿者全員に一律」で運用します（評価の高低で差をつけません）
- お客様から配信停止の申し出があった場合は、運営者へ注文番号をお知らせください（対象外に設定します）
- licenseKey の期限30日前に運営者へ通知が届きます。管理画面「認証情報」から新しいキーに更新してください
- 解約時は、暗号化した認証情報・トークンを削除し、受注データのスプレッドシートは貴店へ譲渡または削除します
