# プライバシーポリシー URL とチェックリスト

## URL

`https://step-samurai.ginzasugiden.com/privacy.html`（リポジトリ直下の `CNAME` のドメイン + `/privacy.html`。`extension/lib/config.js` の `PRIVACY_URL` と同じ値）

ストアの「プライバシーポリシー」欄とオプション画面のリンクの両方に、この URL を使う。**提出前に、公開サイトでこの URL が開き、下記の記載が反映済みであることを確認する。**

## privacy.html が満たすべき記載項目（ストアのポリシーが要求するもの）

- [ ] 拡張機能「ステップ侍 レビュー取込」による取得の記載がある（取得主体は店舗自身。店舗がログインした RMS 画面から取得）
- [ ] 取得する項目: レビュータイプ・レビュー詳細URL・評価・投稿日時・注文番号の5項目
- [ ] 取得しないもの: RMS の ID・パスワード・Cookie、商品名・タイトル・レビュー本文、購入者情報
- [ ] 利用目的: レビューのお礼メールの送信判定、受注との突合
- [ ] 送信先・委託先: 店舗自身の step-samurai（Google Apps Script / 店舗専用スプレッドシート）。Google への委託であること
- [ ] 第三者への販売・目的外の利用・信用審査目的の利用をしないこと
- [ ] 保存場所と期間: 拡張機能内には token 等の設定値のみ（レビューのデータは保存しない）。店舗側の保存期間（既存の記載と整合）
- [ ] 安全管理: HTTPS での送信、店舗ごとの専用トークン、トークンの失効・再発行
- [ ] 解約時の扱い（トークンの無効化、データの削除。規約第8条と整合）
- [ ] 問い合わせ先（運営者名・連絡先）。公開者名は 株式会社GSD
- [ ] 改定日
- [ ] Chrome ウェブストアのユーザーデータポリシー（Limited Use 要件を含む）に従うこと

## 現状メモ

- privacy.html 版 1.1（2026年10月24日）で、第3節「レビュー取込用 Chrome 拡張機能」（`#extension`）として上記の項目を記載済み。受注データの項目と用途は第2節と利用規約の別表。提出前に、公開サイトへ反映済みであることを確認する。
