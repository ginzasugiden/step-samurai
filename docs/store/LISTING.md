## 詳細説明

```
「ステップ侍 レビュー取込」は、楽天市場の店舗さま向けの拡張機能です。
店舗さまご自身がログインした楽天 RMS の「レビューチェックツール」から、レビューの最小項目だけを取り出し、店舗さま専用の step-samurai（Google Apps Script）に送ります。レビューのお礼メール送信の判定に使われます。

【取得する項目（5項目だけ）】
・レビュータイプ
・レビュー詳細URL
・評価（星の数）
・投稿日時
・注文番号

【取得しないもの】
・楽天 RMS の ID・パスワード・Cookie
・商品名・レビューのタイトル・レビュー本文
・購入者の氏名・住所・メールアドレスなどの購入者情報

【使い方】
1. step-samurai の管理画面で発行した「拡張連携トークン」を、拡張機能の設定画面に保存します。
2. 楽天 RMS にログインし、レビューチェックツールを開きます。1日1回、自動で同期します（ポップアップの「今すぐ同期」でいつでも手動同期できます）。
3. 同期が止まったとき（未ログイン・トークン無効・RMS の画面仕様の変更など）は、バッジとポップアップに日本語で案内を表示します。何も送らずに停止します。

【安全面】
・権限は必要最小限です（保存領域、アラーム、楽天 RMS のレビュー画面、Google Apps Script への送信のみ）。
・取得した項目は、店舗さま自身の step-samurai 以外には送信しません。第三者への販売・目的外の利用はしません。
・外部のプログラムコードを読み込みません（リモートコードなし）。
・RMS を勝手に開きません。レビューのデータはこの拡張機能の中に保存しません。

ご利用には、ステップ侍（株式会社GSD）のご契約と拡張連携トークンが必要です。
```
